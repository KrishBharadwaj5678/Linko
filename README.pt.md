<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/icons/Linko.svg" width="35"/> Linko</h1>

<p align="center">
   Linko é uma plataforma moderna de videoconferência desenvolvida para reuniões simples e eficientes, bate-papo em tempo real, compartilhamento de tela e chamadas de vídeo de alta qualidade.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| :--- | :--- |
| 🎥 **Chamadas de Vídeo e Áudio de Alta Qualidade** | Desfrute de comunicação por vídeo e áudio com excelente qualidade. |
| 🔗 **Links Exclusivos para Reuniões** | Crie e compartilhe facilmente URLs exclusivas para suas salas de reunião. |
| 👥 **Suporte a Vários Participantes** | Organize ou participe de reuniões com vários participantes de forma simples e eficiente. |
| 🗨️ **Chat em Tempo Real** | Envie e receba mensagens instantaneamente durante as chamadas. |
| 🖥️ **Compartilhamento de Tela** | Compartilhe sua tela para apresentações, demonstrações ou colaboração. |
| 🔊 **Detecção do Orador Ativo** | Destaca automaticamente a pessoa que está falando no momento. |
| 🔇 **Controles de Silenciar/Ativar Microfone** | Controle seu áudio com apenas um clique. |
| 📷 **Ativar/Desativar Câmera** | Alterne a visibilidade do vídeo conforme necessário. |
| 📲 **Totalmente Responsivo** | Funciona perfeitamente em dispositivos móveis, tablets e computadores. |
| 🛡️ **Salas Seguras e Privadas** | Todas as comunicações permanecem protegidas e seguras. |

## <img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Linko.git
````

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd Linko
```

### 3️⃣ Instalar as Dependências

```bash
npm install
```

### 4️⃣ Adicionar suas Credenciais da ZEGOCLOUD

```text
appID = your_app_id
serverSecret = your_server_secret
```

### 5️⃣ Iniciar o Servidor de Desenvolvimento

```bash
npm run dev
```

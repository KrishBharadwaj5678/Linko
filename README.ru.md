<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/icons/Linko.svg" width="35"/> Linko</h1>

<p align="center">
   Linko современная платформа для видеоконференций, созданная для удобного проведения встреч, общения в реальном времени, демонстрации экрана и высококачественных видеозвонков.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| :--- | :--- |
| 🎥 **Высококачественные видео- и аудиозвонки** | Наслаждайтесь кристально чистым видео и качественным звуком во время общения. |
| 🔗 **Уникальные ссылки на встречи** | Легко создавайте и делитесь уникальными ссылками на комнаты встреч. |
| 👥 **Поддержка нескольких участников** | Проводите встречи с несколькими участниками без лишних сложностей. |
| 🗨️ **Чат в реальном времени** | Отправляйте и получайте мгновенные сообщения во время звонков. |
| 🖥️ **Демонстрация экрана** | Показывайте экран для презентаций, демонстраций и совместной работы. |
| 🔊 **Определение активного спикера** | Автоматически выделяет участника, который в данный момент говорит. |
| 🔇 **Управление микрофоном** | Включайте и отключайте микрофон одним нажатием. |
| 📷 **Включение/выключение камеры** | Управляйте отображением видео по необходимости. |
| 📲 **Полностью адаптивный дизайн** | Отлично работает на мобильных устройствах, планшетах и компьютерах. |
| 🛡️ **Безопасные и приватные комнаты** | Все коммуникации защищены и остаются конфиденциальными. |

## <img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Linko.git
````

### 2️⃣ Переход в директорию проекта

```bash
cd Linko
```

### 3️⃣ Установка зависимостей

```bash
npm install
```

### 4️⃣ Добавление учетных данных ZEGOCLOUD

```text
appID = your_app_id
serverSecret = your_server_secret
```

### 5️⃣ Запуск сервера разработки

```bash
npm run dev
```

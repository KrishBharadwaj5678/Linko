<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/icons/Linko.svg" width="35"/> Linko</h1>

<p align="center">
   Linkoは、スムーズなオンラインミーティング、リアルタイムチャット、画面共有、高品質なビデオ通話を実現する最新のビデオ会議プラットフォームです。

## <img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| :--- | :--- |
| 🎥 **高品質なビデオ・音声通話** | クリアで高品質な映像と音声によるコミュニケーションを楽しめます。 |
| 🔗 **専用ミーティングリンク** | ミーティング用の固有URLを簡単に作成・共有できます。 |
| 👥 **複数参加者対応** | 複数の参加者によるミーティングをスムーズに開催・参加できます。 |
| 🗨️ **リアルタイムチャット** | 通話中にメッセージをリアルタイムで送受信できます。 |
| 🖥️ **画面共有** | プレゼンテーション、デモ、共同作業のために画面を共有できます。 |
| 🔊 **アクティブスピーカー検出** | 現在話している参加者を自動的にハイライトします。 |
| 🔇 **ミュート・ミュート解除** | ワンクリックでマイクのオン・オフを切り替えられます。 |
| 📷 **カメラのオン・オフ** | 必要に応じてビデオの表示・非表示を切り替えられます。 |
| 📲 **完全レスポンシブ対応** | スマートフォン、タブレット、デスクトップで快適に利用できます。 |
| 🛡️ **安全でプライベートなルーム** | すべての通信を安全に保護し、プライバシーを守ります。 |

## <img src="https://github.com/KrishBharadwaj5678/Linko/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Linko.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Linko
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ ZEGOCLOUDの認証情報を追加

```text
appID = your_app_id
serverSecret = your_server_secret
```

### 5️⃣ 開発サーバーを起動

```bash
npm run dev
```
